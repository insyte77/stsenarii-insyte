Датчик освещённости — адаптивная логика

Датчик освещённости подключён к SPIDER2 (Analog Input 1). В проекте 11 датчиков движения ДД-1..ДД-11.
Алгоритм принятия решения
При срабатывании любого триггера (движение / расписание): Если Е(факт) >= Е(порог): → Свет НЕ включать (достаточно естественного) → Открыть шторы (пропустить больше света) Если Е(факт) < Е(порог): → Включить свет на рассчитанный уровень → Яркость = пропорционально дефициту (чем темнее — тем ярче) После открытия штор — перепроверить: → Если теперь Е(факт) >= Е(порог): выключить / снизить свет

Правила приоритетов

  • Тревога (протечка / дым) — переопределяет любой сценарий. Все 100%.
  • Ночной режим — переопределяет ручное включение (кроме санузлов — они по датчику).
  • Ручное управление — переопределяет автоматику (нажал на панели — автоматика не трогает до следующего сценария).
  • Геофенсинг «Уходим» — переопределяет любое ручное включение.
