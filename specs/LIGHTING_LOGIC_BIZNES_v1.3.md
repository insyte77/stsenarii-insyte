> **Версия:** 1.0 | **Дата:** 2026-07-08  
> **Назначение:** Схема связей помещений и правила автоматического освещения по трассам движения человека

## 3. ТРАССЫ ДВИЖЕНИЯ ЧЕЛОВЕКА

### Трасса А — «Приход домой» (базовая)
```
УЛИЦА → П01 Прихожая → П02 Гардеробная (снять верхнюю одежду)
                      → П03 Коридор общий → П04 Кухня-гостиная
```
**Свет при входе:** П01 + П02 + П03 + П04

---

### Трасса Б — «Из гостиной в спальню» (вечерняя)
```
П04 Кухня-гостиная → П03 Коридор общий → П10 Мастер-спальня → П11 Мастер-санузел
```
**Свет:** П04 гаснет → П03 горит → П10 включается → П11 по требованию

---

### Трасса В — «Из гостиной в детское крыло»
```
П04 Кухня-гостиная → П03 Коридор общий → П06 Коридор детский → П07 или П08 Детская
                                                              → П09 Детский санузел
```
**Свет:** П03 + П06 + нужная детская комната

---

### Трасса Г — «Ночной поход в санузел» (мастер-крыло)
```
П10 Мастер-спальня → П11 Мастер-санузел (через внутреннюю дверь, en-suite)
```
**Свет:** П10 остаётся 5% ночник → П11 включается 15% (ночной режим)

---

### Трасса Д — «Ночной поход детей в санузел»
```
П07 или П08 Детская → П06 Коридор детский → П09 Детский санузел
```
**Свет:** П06 включается 10% → П09 включается 10%

---

### Трасса Е — «Утилитарные»
```
П03 Коридор общий → П05 Кладовая        (взять/убрать вещи)
П03 Коридор общий → П12 Постирочная     (стирка, котёл)
```
**Свет:** только нужное помещение — автовключение по датчику двери/движения

---

## 4. ЗОНЫ ОСВЕЩЕНИЯ

Помещения сгруппированы в зоны — включаются и выключаются вместе по логике сценария.

| Зона | Помещения | Описание |
|------|-----------|----------|
| **ЗОНА 1 — Входная** | П01 + П02 + П03 | Всегда включается при приходе. Базовая навигация по дому |
| **ЗОНА 2 — Гостиная** | П04 | Главная социальная зона. Включается при приходе, гаснет последней |
| **ЗОНА 3 — Детское крыло** | П06 + П07 + П08 + П09 | Включается только при движении в детскую сторону |
| **ЗОНА 4 — Мастер-крыло** | П10 + П11 | Включается только при движении к спальне |
| **ЗОНА 5 — Утилитарные** | П05 + П12 | Автономная автоматика, независимо от других зон |

## 5. ЛОГИКА ВКЛЮЧЕНИЯ СВЕТА ПО СОБЫТИЯМ

### 5.1 СОБЫТИЕ: «Человек пришёл домой»

| Действие | Помещение | Яркость | Задержка |
|----------|-----------|---------|----------|
| Включить | П01 Прихожая | 100% | 0 сек |
| Включить | П02 Гардеробная | 80% | 0 сек |
| Включить | П03 Коридор общий | 80% | 0 сек |
| Включить | П04 Кухня-гостиная | 60% | 5 сек |
| НЕ включать | П06, П07, П08, П09 | — | ждём движения |
| НЕ включать | П10, П11 | — | ждём движения |
| НЕ включать | П05, П12 | — | автономно |

**Логика угасания:** Если 15 мин. нет движения в П01 → П01 снижается до 20%

---

### 5.2 СОБЫТИЕ: «Движение из П03 → в сторону П06»

Датчик движения в П03 фиксирует направление к П06 (или датчик в П06 срабатывает):

| Действие | Помещение | Яркость | Задержка |
|----------|-----------|---------|----------|
| Включить | П06 Коридор детский | 70% | 0 сек |
| НЕ включать автоматически | П07, П08, П09 | — | ждём, в какую дверь войдут |
| Включить при входе | П07 или П08 или П09 | 80% / 80% / 100% | по датчику двери |

---

### 5.3 СОБЫТИЕ: «Движение из П03 → в сторону П10»

| Действие | Помещение | Яркость | Задержка |
|----------|-----------|---------|----------|
| Включить | П10 Мастер-спальня | 70% | 0 сек |
| П04 Кухня-гостиная | Плавно снизить до 20% | — | 2 мин после выхода из П04 |

---

### 5.4 СОБЫТИЕ: «Ночь — режим активирован» (23:00 / кнопка)

| Действие | Помещение | Яркость |
|----------|-----------|---------|
| Выключить | П04 Кухня-гостиная | 0% |
| Выключить | П07, П08 Детские | 0% |
| Снизить до ночника | П10 Мастер-спальня (LED-лента) | 5% |
| Снизить до навигации | П01 Прихожая | 5% |
| Снизить до навигации | П03 Коридор общий | 5% |
| Снизить до навигации | П06 Коридор детский | 5% |
| Выключить (ждут датчика) | П09, П11 Санузлы | 0% |

---

### 5.5 СОБЫТИЕ: «Ночное движение» (22:00–07:00)

Человек встал ночью. Датчик движения фиксирует активность.

**Алгоритм:**

```
Датчик сработал в П10 (спальня)
  → Если движение к П11 (en-suite): П11 включить 15%
  → Если движение к П03 (коридор): П03 включить 5%
      → Если движение к П06 (детское): П06 включить 10%
          → П09 включить 10%
      → Если движение к П11 (санузел через коридор): П11 включить 15%
  → Возврат в П10: всё гасить через 5 мин.
```

**Принцип:** ночью свет включается только на пути — не заливает весь дом.

---

### 5.6 СОБЫТИЕ: «Уходим из дома»

| Действие | Помещение | Яркость | Задержка |
|----------|-----------|---------|----------|
| Плавно выключить | П04 Кухня-гостиная | 0% | 0 сек |
| Плавно выключить | П03 Коридор общий | 0% | 3 сек |
| Плавно выключить | П02 Гардеробная | 0% | 5 сек |
| Последним | П01 Прихожая | 0% | 10 сек (после закрытия двери) |
| Проверить и выключить | все остальные | 0% | 0 сек |

**Логика:** свет гаснет в обратном порядке движения — как будто «провожает» до двери.

## 6. ПРАВИЛА ПРИОРИТЕТОВ

1. **Тревога (протечка / дым)** — переопределяет любой сценарий. Все 100%.
2. **Ночной режим** — переопределяет ручное включение (кроме санузлов — они по датчику).
3. **Ручное управление** — переопределяет автоматику (нажал на панели — автоматика не трогает до следующего сценария).
4. **Геофенсинг «Уходим»** — переопределяет любое ручное включение.

## 9. ДАТЧИК ОСВЕЩЁННОСТИ — АДАПТИВНАЯ ЛОГИКА

> ⚠️ Уточнить у инженера: наличие датчика освещённости в проекте.  
> В тексте проекта Бизнес-версия v1.3 отдельный датчик освещённости не упоминается.  
> В проекте есть 11 датчиков движения (ДД-1–ДД-11) — некоторые модели совмещают PIR + люксметр.

### Принцип адаптивного освещения

Искусственный свет включается **только когда естественного недостаточно**.  
SPIDER2 читает показание датчика освещённости (лк) перед каждым решением о включении.

```
Алгоритм для каждого помещения при срабатывании триггера:

  Если Е(факт) >= Е(порог):
      → Свет НЕ включать (достаточно естественного)
      → Шторы открыть (пропустить больше света)

  Если Е(факт) < Е(порог):
      → Включить свет на рассчитанный уровень
      → Яркость = пропорционально дефициту: чем темнее — тем ярче

  После открытия штор — перепроверить:
      → Если теперь Е(факт) >= Е(порог): свет выключить / снизить
```

### Пороги освещённости (настраиваются в приложении)

| Ситуация | Порог | Пример |
|----------|-------|--------|
| Утро — включить ли свет | 200 лк | Зима 07:00 — темно (30 лк) → свет вкл. |
| Утро — включить ли свет | 200 лк | Лето 07:00 — светло (800 лк) → свет НЕ вкл. |
| День — поддержка рабочего освещения | 300 лк | Пасмурный день (100 лк) → свет вкл. |
| Вечер — когда включить | 100 лк | Закат (80 лк) → свет вкл. |

### Применение по помещениям

| Помещение | Датчик освещённости | Адаптивная логика |
|-----------|--------------------|--------------------|
| П04 Кухня-гостиная | Основной (уличный свет через окна) | Утро, день — главный датчик дома |
| П10 Мастер-спальня | По датчику гостиной или отдельный | Утро — не включать если светло |
| П07, П08 Детские | По датчику гостиной | Утро — не включать если светло |
| П01 Прихожая | Нет окон — датчик не нужен | Всегда включать по движению |
| П02 Гардеробная | Нет окон | Всегда включать при входе |
| П03, П06 Коридоры | Нет окон | Всегда включать по движению |
| П09, П11 Санузлы | Нет окон | Всегда включать по движению |

### Сезонный эффект (без дополнительных настроек)

| Месяц | Рассвет (Москва) | В 07:00 | Результат |
|-------|-----------------|---------|-----------|
| Декабрь | 09:00 | Темно, ~10 лк | Свет включается |
| Март | 06:30 | Светло, ~300 лк | Свет НЕ включается |
| Июнь | 04:45 | Очень светло, >500 лк | Свет НЕ включается |
| Сентябрь | 07:00 | Пасмурно, ~50–150 лк | Зависит от погоды |

Система автоматически адаптируется к сезону и погоде — без перепрограммирования.
